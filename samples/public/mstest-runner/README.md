# MSTest runner samples

| Sample | What it demonstrates |
| --- | --- |
| [`Simple1`](Simple1) | A basic MSTest runner project with method-level parallelization and code coverage. |
| [`CustomReportExtension`](CustomReportExtension) | A test-result console reporter registered through an explicit entry point. |
| [`EnsureTestFramework`](EnsureTestFramework) | A custom testing framework plugged into Microsoft.Testing.Platform. |
| [`MSTestProjectWithExplicitMain`](MSTestProjectWithExplicitMain) | Registering MSTest and extensions in an explicit entry point. |
| [`NativeAotRunner`](NativeAotRunner) | Publishing a runner using Native AOT and source generation. |
| [`RunInDocker`](RunInDocker) | Running integration tests against an application inside a Docker image. |
| [`runner_vs_vstest`](runner_vs_vstest) | Comparing runner and VSTest execution on large test suites. |

The former WinUI examples have moved: see
[`MSTestRunnerWinUI`](MSTestRunnerWinUI) and
